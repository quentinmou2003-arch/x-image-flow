# 拾图 · X Image Flow 2.3.11

## 2.3.11 顺序收图与点赞自动复制

- 默认「顺序收图」，从左到右逐行浏览，点赞和图片加载后不再换列；保留瀑布流选项。
- 默认开启点赞自动复制，只有添加点赞成功才复制，取消点赞与添加书签不复制。
- 单张图直接复制 PNG；识别为切片的图集自动排序、拼接后复制；普通多图通过 Windows 小助手复制整套独立 PNG。
- 第一次使用整组复制：点顶部「多图助手 → 复制插件 ID」，双击 native 文件夹中的「安装小助手.cmd」，粘贴 ID，回到拾图检查连接。
- 卡片显示待复制和已复制几张，刷新后保留本标签页最近 2000 张的记录。复制失败时点赞保留，可点「整组」重试。
- 复制记录不代表已发送 QQ。去 QQ 粘贴上一组再收下一组；QQ 可能按图片或文件附件接收，请先试发一组。
- 小助手主体约 14 KB，按需启动后退出，不联网、不常驻。详细安装与卸载见 native/使用说明.md。

## 2.3.10 自动过滤推广与广告

- 默认在拾图图库中过滤 X 明确标记的推广与广告，图片、视频和广告携带的引用媒体均适用。
- 顶部「广告已屏蔽」可切换，偏好自动保存。关闭过滤可以重新查看本轮收集的广告。
- 同时检查页面标记及 X 已返回的推广数据；广告标记晚到时移除卡片并整理瀑布流。
- 普通推文只提到广告或作者名为 Ad 不会因此被过滤；正常推文中的引用原图保留。
- 只作用于拾图图库，不识别没有广告标记的软推广，也不阻止 X 原网页自己的请求。
- 已完成模拟数据和浏览器测试；X 的真实标记变化可能影响识别。

## 2.3.9 卡片右上角更多菜单

- 点击卡片右上角「⋯」，直接显示 X 原帖的完整菜单：不感兴趣、取消关注、列表、隐藏账号、屏蔽、举报等。实际选项由 X 根据推文与账号状态决定，保留原生图标和后续确认弹窗。
- 操作由 X 原网页自己的处理程序和接口执行，不猜测或重复发送账号操作；举报、屏蔽等仍按 X 的确认流程进行。
- 原帖已离开页面或来自引用时，在当前标签页临时定位原帖，关闭菜单后回到原页面，保留当前图库。不会新开标签页。若 X 未载入原帖，显示重试和本地隐藏选项。
- 「仅在拾图隐藏这条」立即移除整条推文并保存到浏览器本地，刷新后也不再显示。提示中可撤销，图库上方「已隐藏」可随时恢复。
- 点击 X 的「不感兴趣」「隐藏」时，也会本地隐藏当前推文；X 的账号或推荐调整是否成功，以 X 的实际结果为准。本地隐藏本身不会改变 X 推荐、取消关注或屏蔽账号。
- 已完成模拟菜单、确认弹窗、原帖定位、撤销、刷新恢复与跨标签页验证；真实 X 的页面结构或路由变化仍可能影响原菜单，需要在实际账号中验证。

## 2.3.8 固定大图切换按钮

- 上一张、下一张按钮固定在预览区左右两侧中间，切换横图、竖图及缩放时保持位置。
- 加大按钮点击范围，窄屏下保留图片与按钮的间距。


## 2.3.7 网页接口同步

- 点赞与书签优先通过当前 X 页面直接调用网页接口，不再打开后台推文标签页。
- 首次使用，在 X 原网页正常点赞、添加书签各一次即可学习；取消点赞和取消书签也分别学习一次。插件内有提示和返回 X 按钮。
- 当前页面仍有原生按钮时可直接执行并自动学习；否则未准备好的接口只显示提示。
- 接口格式自动保存在浏览器本地，不保存账号密码、Cookie 或授权请求头。登录请求头只在 X 页面内存使用，刷新后从正常网页请求重新获取。
- 不重试已发送的账号操作，只有 X 明确确认成功后才更新状态。网页私有接口变化后可能需重新学习。


## 2.3.3 连续收图

- 取消 600 组上限，X 返回新内容时可继续向下加载。
- 远处卡片保留占位，卸下预览图并跳过内部渲染；回滚时重新加载。
- 本轮记录仍保留，长时间使用的内存并非完全固定；刷新页面清空记录。

## 2.3.2 超长图折叠

高度超过宽度 2.6 倍的图片显示顶部限高预览，底部提示「长图 · 点击查看完整图片」。卡片预览最高 560 像素且不超过窗口高度的 65%，避免长图撑坏瀑布流。点击后查看完整原图，复制、下载和拼接不裁切。

## 2.3.1 作者主页

点击卡片下方作者昵称或 ID，在新标签页打开对应 X 主页，保留当前收图位置。引用图片链接到原作者主页。

## 2.3.0 图片缩放

点开图片后可用滚轮或底部加减按钮缩放，放大后按住图片拖动。双击放大或还原，「适应」恢复全图，「原尺寸」按原图像素查看（最高放大到适应尺寸的 16 倍）。切换图片自动重置缩放。

## 2.2.9 引用图片作者

引用推文图片显示「引用 · 原作者 @账号」。昵称不可用时显示来源账号；无法识别时明确提示，不把转发者当成原作者。

## 2.2.8 推文点赞与收藏数量

移除顶部列表计数。每张卡片的喜欢、书签旁显示该推文的点赞数、收藏数，来自 X 页面已收到的数据；未返回的数字显示「—」，不会冒充 0。超过一万简写为「万」，悬停可查看完整数字。

## 2.2.6 返回首页收图

历史喜欢、书签页面新增「回首页收新图」，返回后自动打开拾图，可继续切换「为你推荐 / 正在关注」。历史列表的「全部」改名为「本页全部」，表示只筛选当前列表。

## 2.2.5 在拾图中浏览历史收藏

点击顶部「喜欢」「书签」后，切换到对应 X 历史页面并自动打开拾图，无需再次点击启动按钮。图库从该历史列表重新收集图片与视频，不混入上一页内容；历史内容随 X 分批加载，可继续下滑浏览。

## 2.2.4 像素 X 图标

工具栏和扩展管理页使用蓝白色、粉色腮红的可爱像素 X 图标。

## 2.2.3 删除拼接片段

每个拼接片段右侧新增「×」删除按钮，只从本次拼接中移除，原推文和图库图片保留。删除后自动更新预览与接缝；不足两张时暂停拼接导出。

## 2.2.2 历史喜欢与书签

顶部「喜欢」「书签」直接在当前标签页打开本人 X 历史喜欢、书签页面，不再筛选本次收集内容。新版会自动保持拾图模式。卡片上的喜欢和书签按钮仍用于收藏当前推文。

## 2.2.1 缩略图加载优化

缩略图改为按图库视口分批加载，屏幕中的图片优先，远处卡片不再同时占用网络连接。等待期间显示带动画的占位卡，加载失败会显示明确提示，避免瀑布流中出现整列黑色空白。图片真实尺寸到达后，图库会在滚动停下的空闲时间重新平衡各列，并保持当前阅读位置。切换密度、筛选或重新打开图库时会重新检查当前可见区域。

## 2.2.0 主页来源切换

在 X 主页打开图库后，顶部会显示「为你推荐 / 正在关注」。点击即可切换 X 原生主页来源，图库保持打开并继续收集内容；两个来源已经收集到的图片和视频会自动合并。切换不会模拟关注、点赞或其他账号操作。

## 2.1.3 接缝对齐修复

修正纵向匹配方向和偏移符号，使用原图进行整数像素对齐。仅在匹配可靠时去掉重复部分，不再使用上一版无效的融合。预览与导出使用同一份对齐结果，先完成原尺寸合成，再缩小预览。

新增每条接缝的「重叠」「上下／左右偏移」微调，单位为原图像素。偏移正数向下／向右，负数向上／向左；重叠为 0 时保持相邻排列。切换方向、顺序或自动开关会重置微调。预览、复制与保存使用同一组参数。

不能保证所有图片集无缝还原：若原切片之间有内容缺失、不同缩放或形变，简单拼接无法恢复缺失细节。匹配不可靠时保留原位置并提示，避免误裁。已用用户提供推文的四张原图验证：没有可靠重叠，不自动修改接缝；这组图仍不能仅靠对齐实现无缝还原。

## 2.1.1 复制 PNG 修复

复制 PNG 现在由你正在点击的 X 页面写入剪贴板，解决 `Document is not focused`。点击“复制 PNG”后留在 X 页面，等提示“已复制 PNG”再切换 QQ 粘贴。若复制时切换了窗口，返回 X 后再点一次；已准备的 PNG 会复用，不会重新下载。

## 2.1 视频与轻量预览
- 视频和 GIF 动图加入信息流，与图片共用卡牌切换、喜欢和书签。
- 顶部增加「图片」「视频」筛选。混合推文会同时出现在这两个分类，卡牌保留完整媒体组。
- 图片瀑布流使用较小的 small 预览，放大查看、复制和导出仍用全尺寸原图。
- 视频卡牌先加载封面，不主动预取视频文件。点击 ▶ 或「播放视频」打开播放器，默认静音、选择 X 提供的最低码率 MP4；可用播放器音量按钮开启声音，也可切换清晰度、拖动进度、全屏。
- 关闭播放器后暂停并释放播放地址；切到其他标签页时暂停。图片流背后的 X 原生视频会在画廊打开时暂停，但 X 页面自身已经发出的网络请求不由插件控制。
- 视频清晰度取决于 X 提供的版本，不能保证每条视频都有 360p 或更低版本。原推文入口始终保留。
- 为兼容 X 的 blob 播放器，插件在页面启动时读取 X 自己已请求的时间线响应，只提取推文编号、视频封面和 MP4 版本信息；视频提取不主动调用额外 X 接口。点赞和书签接口在用户点击时调用，登录凭据只在页面内存使用，不保存账号密码。
- 升级后必须刷新 X 页面，以便捕获视频信息。若仅有 HLS、直播、受限制媒体或未读到可播放地址，会提供原推文播放入口；本版不对视频截图拼接、不提供视频下载。

视频使用本地生成的 MP4 做过浏览器实播测试：确认点击前不请求视频、优先低码率、清晰度切换、关闭释放、混合媒体卡牌和收藏交互。X 真实页面接口可能变化，实际账号页面仍需验收。

## 从旧版升级
1. 用新版文件夹替换原插件文件夹内的文件，或在 Chrome 扩展管理页移除旧版后加载新版。
2. 在 chrome://extensions 找到「拾图」，点击刷新按钮。
3. 刷新已经打开的 X 页面。升级后版本号应为 2.3.11。

## 新版功能
- X 风格：黑色背景、灰色边框、蓝色主按钮，喜欢使用粉色。
- 多图卡牌：同一推文的 2–4 张图片合为一组；悬停显示左右切换按钮，角标显示当前张数。复制和保存针对当前这一张。
- 拼接：多图卡牌点击「拼接」；边缘检测认为可能是连续切片时显示「疑似切片」。支持横向、纵向、四宫格，先看预览，再复制或保存合成 PNG。↑ ↓ 调整片段顺序。
- 跨推文拼接：悬停后点击图片左上角 + 选择当前图片，再点顶部「拼接已选」。最多 4 张，再次点勾号可取消选择。
- 喜欢 / 书签：点击直接操作 X 对应推文，整组图片共用状态。再次点击取消。按钮确认 X 页面状态变化后才显示成功。
- 顶部「喜欢」「书签」进入本人的历史列表并保持拾图模式；随 X 页面逐步加载，不一次性下载整个收藏库。
- 极速预取：提前约两屏加载信息流；悬停 180 毫秒后预取当前原图及下一张预览。原图请求去重，最多四个并发，短期缓存上限约 96 MiB。点「极速预取」可切换按需模式。

拼接检测比较相邻图片边缘的颜色和变化，支持自动建议方向与顺序；不是图像语义 AI，可能漏检或误判。始终保留手动调整，并在导出前检查接缝。支持重叠与偏移调整；暂不支持透视矫正或缺失部分补全。

拼接使用 X 返回的 name=orig 原图，不缩放切片；对齐会覆盖重叠区域，外沿空白区域透明。首次拼接需要加载原图，后续调整复用缓存。单次合成上限 8000 万像素，单边不超过 32767 像素。

X 会回收已滚出屏幕的推文。新版学习网页接口后，仍可直接同步这类旧推文和引用推文的点赞、书签。不再新开推文标签页。需要保持 X 登录；接口尚未学习或被 X 拒绝时，返回 X 正常操作。请求超时不自动重试，请先检查原推文状态。

## 安装
1. 解压 ZIP；保留整个 x-image-flow 文件夹。
2. Chrome 地址栏打开 chrome://extensions，开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 manifest.json 的 x-image-flow 文件夹。
4. 打开或刷新 https://x.com/home，登录你的 X 账号。
5. 点击右下角「拾图 · 只看图片」。也可固定扩展图标并点击切换。

## 使用
- 舒适 / 紧凑 / 大图三种密度，设置会保存。
- 点击图片放大；Esc 关闭预览，再按一次返回 X。
- 极速模式会提前滚动原 X 页面收集更多图片；也可点击「继续加载图片」。每批最多滚动四次，发现足够新图片可提前结束，无新内容时停止自动预取。
- 「复制 PNG」读取 X 的 name=orig 图片，不缩小尺寸，转换为 PNG 写入系统剪贴板。
- 在电脑 QQ 中打开你用于向手机传文件的会话（例如「我的手机」，名称以实际版本为准），Ctrl+V 后手动发送。
- 要保留 PNG 文件本身：点 ↓ 保存 PNG，再通过 QQ 作为文件发送到手机。粘贴发送的处理方式由 QQ 决定，插件无法保证 QQ 不转码。

## 范围与限制
- 不会自动登录、打开 QQ 会话或发送消息；本版本没有 QQ 自动直传功能。
- PNG 是无损编码，但从 X 的 JPEG/WebP 转换无法恢复此前压缩丢失的细节；转换可能改变色彩元数据，不承诺与上传者原始文件逐字节一致。
- 只展示当前 X 页面 DOM 中已经加载的推文媒体；跳过头像，视频封面用作播放入口。敏感内容需先在 X 手动展开。
- X 的 DOM 或媒体地址规则改变时可能需要更新，尤其是喜欢/书签按钮。画廊不再限制 600 组；X 暂无新内容时可稍后重试，刷新页面清空本轮记录。
- 返回 X 后可切换关注/推荐/搜索，再重新进入画廊。加载图片会推进原页面滚动位置。
- 需要 Chrome 116+。浏览器或系统策略可能限制剪贴板；复制失败可使用保存 PNG。
- 无第三方服务、无统计、无账号密码读取。权限用于扩展图标对当前标签页的操作、写剪贴板、后台图像转换、用户触发的文件下载、保存设置，以及读取 pbs.twimg.com 图片。X 互动通过当前已登录页面的网页接口或原生按钮完成。

## 验收
在登录 X 的 Chrome 中检查：多图卡牌、持续加载、切换页面、三种密度、原推文链接、喜欢/取消喜欢、书签/取消书签、拼接排序与原尺寸导出；在 QQ 粘贴检查图片尺寸，并通过文件发送验证手机收到的 PNG。

本次开发使用 Chromium 加载测试扩展与模拟 X 页面，验证卡牌、按钮同步、拼接交互，以及合成 PNG 的逐像素一致性。测试用图片和页面是本地构造的，未对你的真实 X 账号发送点赞或书签操作；真实账号同步与 QQ 收图需在你的环境中验收。

开发使用 Manifest V3 与 Chrome offscreen API：https://developer.chrome.com/docs/extensions/reference/api/offscreen
