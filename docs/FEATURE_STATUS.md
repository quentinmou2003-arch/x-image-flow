# 功能实现状态

适用版本：**Chrome 扩展 v2.3.11** · 核对日期：**2026-10-14**

[返回项目首页](../README.md) · [下载当前版本](https://github.com/quentinmou2003-arch/x-image-flow/releases/tag/v2.3.11) · [隐私说明](../PRIVACY.md)

本表以仓库中的 Chrome 扩展源码为准，区分功能是否实现、验证到哪一步，以及使用时的限制。**“已实现”表示已有对应代码，不表示所有真实 X 页面都已验证。**

| 实现状态 | 含义 |
| --- | --- |
| **已实现** | 已有对应界面和处理逻辑 |
| **已实现 · 依赖 X** | 已有实现，仍依赖 X 页面、接口、登录状态或已返回的数据 |
| **部分实现** | 已提供部分流程，尚不能完成整个目标 |
| **未提供** | 当前公开 Chrome 版本不包含此功能 |

| 复制 PNG | **已实现** | 读取 X 的原尺寸媒体，在当前页面写入剪贴板；需要页面保持焦点与浏览器许可 | 模拟浏览器交互；真实系统剪贴板待验收 |
| 点赞成功后自动复制 | **已实现 · 依赖 X** | 单张 PNG 直接复制；切片按检测结果自动拼接；普通多图用小助手整组复制。取消点赞不复制，失败保留点赞 | 模拟点赞失败与实际剪贴板；真实 X 待验证 |
| 独立多图整组剪贴板 | **已实现** | 需要安装 Windows 小助手；1–4 张 PNG 写入文件剪贴板，QQ 可能按图片或文件附件接收 | 真实 Chrome Native Messaging 与 Windows 文件列表、原顺序及文件字节验证；QQ / 手机待验收 |
| 复制进度 / 整组重试 | **已实现** | 本标签页记住最近 2000 张已复制图片；不等于已发送 QQ | 模拟失败、重试与刷新后的进度 |
| 保存 PNG | **已实现** | 生成并下载原尺寸 PNG；JPEG 转 PNG 不会恢复已丢失的细节，也不承诺与上传者文件逐字节一致 | PNG 输出与尺寸验证 |
| 发送到 QQ 手机会话 | **部分实现** | 提供复制、保存和发送指引；仍需用户在 QQ 粘贴或以文件发送 | QQ 与手机接收端待验收 |
| 横拼 / 竖拼 / 四宫格 | **已实现** | 使用原尺寸切片合成 PNG，支持预览、复制和保存；有尺寸与像素总量上限 | 几何自动测试；合成结果逐像素验证 |
| 切片方向与顺序建议 | **已实现** | 比较图片边缘给出建议；可能误判，无法确认时保留手动拼接 | 构造切片与模糊匹配样例 |

| 调整顺序 / 删除片段 | **已实现** | 仅修改当前拼接任务，删除后重新生成预览；不足两张时停止合成导出 | 模拟拼接交互 |
| 跨推文拼接 | **已实现** | 可选择 2–4 张图片合成，支持取消选择 | 模拟跨推文选择 |

## 互动与隐藏

| 功能 | 实现状态 | 当前能力与限制 | 验证范围 |
| --- | --- | --- | --- |
| 点赞 / 取消点赞 | **已实现 · 依赖 X** | 学习网页请求格式后在当前页面调用；未准备好时提示回 X 操作，已发送的请求不自动重试 | 模拟网页接口与原生按钮；真实 X 待验证 |
| 添加 / 取消书签 | **已实现 · 依赖 X** | 添加和取消分别学习；整条推文共用状态，只有确认成功后才更新显示 | 模拟网页接口与原生按钮；真实 X 待验证 |
| 推文喜欢 / 书签数量 | **已实现 · 依赖 X** | 显示 X 已返回的推文计数；未知显示「—」，不冒充 0 | 计数自动测试与模拟数据 |
| 卡片右上角更多菜单 | **已实现 · 依赖 X** | 尝试打开原帖的 X 菜单，保留原生选项与后续弹窗；并非独立重做所有菜单项 API | 模拟菜单、举报取消与 Escape；真实 X 待验证 |
| 旧推文 / 引用原帖定位 | **已实现 · 依赖 X** | 原帖不在页面时尝试在当前标签页临时定位；关闭后返回并保留图库，不新开互动标签页 | 模拟原帖定位与返回；真实 X 路由待验证 |
| 本地隐藏推文 | **已实现** | 隐藏整条推文并保存到浏览器本地，刷新后仍生效；菜单不可用时也可本地隐藏 | 模拟隐藏、刷新与菜单失败场景 |
| 撤销 / 管理已隐藏 | **已实现** | 可撤销或逐条恢复，同一浏览器的其他打开图库同步更新 | 模拟恢复与跨标签页同步 |
| X 推荐及账号调整 | **已实现 · 依赖 X** | 不感兴趣、隐藏账号、屏蔽、取消关注、列表和举报交给 X 原菜单处理；各项实际可用性与结果由 X 决定 | 原菜单入口和部分后续弹窗模拟；各项真实账号结果待验证 |

**本地隐藏与 X 账号操作是两件事。** 点击 X 菜单的“不感兴趣”“隐藏”等已匹配选项时，拾图也会本地隐藏当前推文；本地移除不代表 X 服务已经确认成功。恢复本地隐藏不会自动撤销 X 的屏蔽、隐藏账号或推荐反馈。
