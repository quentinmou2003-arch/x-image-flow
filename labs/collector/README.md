# 拾图 · 收藏实验室

## 批量勾选复制（2.3.17 / 实验版 lab.8）

在「历史喜欢」的拾图界面点击顶部「批量复制」，卡片下方会展开每张照片的选择缩略图。逐张勾选，点击「复制所选 N 张」，然后切到 QQ 按 Ctrl+V。按勾选顺序放入多张独立 PNG，不自动发送，不改变 X 的点赞状态。

每批 1–20 张；切片也保留独立片段，可自行选需要的图片。本功能不自动拼接，也不包含 GIF 和视频；GIF 继续使用单独的「复制 GIF」。相同图片地址只选一次。支持清空、退出，失败保留选择；准备时切走页面会等待你回来再次点击复制。

**先重新运行 native/安装小助手.cmd，升级助手到 1.2.0**。每张最多 40 MB、整批最多 200 MB，解码像素也有上限。逐张准备以控制内存，完整准备后一次提交，避免失败只复制半套。QQ 可能显示为多张图片或文件，取决于 QQ 版本，请先试粘贴，不会自动发送。已验证真实 Windows 文件剪贴板，未验证真实 QQ 会话。

独立特别版 **2.4.0-lab.8**（Chrome 内部版本 2.4.0.8），核对日期 2026-11-05。稳定版仍为 2.3.17，本版不替换稳定版的安装包。

目标是让收图从“刷到、复制”继续走到“留存、找回、整理”。原有顺序收图、图集、自动复制、拼接、点赞、书签、推广过滤和本机多图助手保留。

## 点赞自动收下与性能

默认开启「点赞自动收下」，仅在拾图中新增点赞成功后保存整组照片原文件、顺序与出处；可在顶部关闭。取消点赞、点赞失败和历史已有点赞不触发保存，视频与 MP4 形式动图暂不归档。复制与保存是独立任务，取消点赞不自动删图。

任务先写入本机数据库，中断后恢复；失败自动按 1、2、4、8 分钟间隔重试，五次失败后手动重试。本地库可查看队列与错误。只在整组保存成功后显示已收下。浏览器关闭期间不处理，重新启动后续办。

容量统计使用大小索引，不读出全部原图；封面靠近视口才从数据库读取。队列状态更新只刷新队列，避免反复重建卡片；只查询未完成任务，不扫描已完成历史。旧库升级保留收藏和标签。

Google Drive 接入已实现于 lab.8，需按安装包内《Google Drive 使用说明》配置 OAuth 客户端，再主动点击「连接并同步收藏」。连接后同步本机已有和后续收下的照片原文件及作者、出处、图序、标签清单；切片仍保存每张原片，不以拼接图替代。原文件哈希去重，按账号隔离续传与任务状态，整组及清单校验完成后才显示已入云。断开连接保留云端文件。本版无双向恢复和自动分类；真实 Google 登录上传尚待用户账号验收，未连接前仍只存本机。

## 复制 GIF

- GIF 卡片、动图播放窗口和原 GIF 大图预览提供「复制 GIF」，通过小助手写入真正的 GIF 文件与 GIF 剪贴板格式，不附加静态 PNG / Bitmap。
- 源文件本身是 GIF 时保留字节、透明关系、帧延时和循环；X 以 MP4 提供的动图在浏览器本地完整转换，不上传转换网站、不依赖 FFmpeg。
- 视频形式转 GIF 最多 640 像素长边、约 12 帧 / 秒、256 色；为控制资源，长动图可能进一步缩小。支持 2 分钟以内且输入 / 输出不超过 40 MB，超限提示失败，不截取前几秒冒充完整动图。
- **已有用户须重新运行 native/安装小助手.cmd 升级到 1.2.0**；旧助手会明确提示升级。普通单图 PNG 不需要小助手。

## 自动续载

- 打开拾图即自动补充内容，接近图库底部、继续向下滚动或触碰底部时自动续载，不必点加载按钮。
- 自动续载不再依赖「极速预取」开关；该开关只影响图片预取与提前加载距离。
- X 暂无新图片时按 2、4、8、16、30 秒逐渐延长间隔重试，不再一次空批次就永久停止。保留手动立即重试。
- 只准备附近几屏；关闭拾图、打开大图或菜单、切到后台、断网时暂停。识别原页面滚动容器，支持媒体页内部滚动。

## 返回作者主页

- 作者主页、媒体页中新增「@ID 主页」入口，在当前标签页打开作者主页并退出拾图，不新开页面。
- 顶部退出按钮按入口显示「返回媒体页」「返回 @ID」「返回 X 首页」等，避免把作者页与 X 首页混淆。
- 从图库切换历史喜欢、书签或首页时，本标签页保留最初入口；顶部返回按钮可回到原页面。「回首页收新图」仍是独立入口。

## 连接恢复

- 等待图片处理接收端真正就绪后才发请求，并发操作共用一次启动。处理端意外断开时，图片准备最多恢复一次。
- 复制、拼接预览、下载、整组复制和特别版离线整组复制使用同一连接检查。不会重发点赞、收藏或 Windows 剪贴板提交。
- 图片处理端的错误不再误判成后台断线；后台首次唤醒失败会短暂自动重试，持续失败时可在横幅点「重试连接」。

隔离 Chromium 中验证延迟 1.2 秒注册接收端、并发图片请求、处理页关闭后重建、就绪后瞬间断开恢复，以及实际拼接窗口。未使用真实登录 X 或 QQ。

## 试用

下载预发行页中的 x-image-flow-lab-v2.4.0.8.zip，解压后覆盖原特别版目录，重新加载并刷新 X。ZIP 根目录直接包含 manifest.json。

**试用时在 Chrome 扩展管理页暂时关闭稳定版，不必卸载**，避免两个拾图同时在同一 X 页面工作。关闭特别版并重新启用稳定版即可回退。

特别版有独立的插件 ID、偏好和收藏库。普通多图剪贴板需要在「多图助手」复制本版 ID，重新运行 native/安装小助手.cmd 登记；安装器保留原来允许的 ID。

在 X 卡片点「收下」保存整条推文的照片与出处，点击顶部「本地库」查看。**收下不触发 X 点赞或书签**。仅收照片，视频暂不归档。

## 数据与边界

收藏库和待处理队列存在本扩展自己的 IndexedDB 中，不上传到项目维护者或独立服务器。手动收下或开启自动收下后的新增点赞会获取原图；作者和来源随图保存。精确重复提醒与去重不等于相似图片识别。

仅归档 X 推文照片，一组最多四张；单文件上限 64 MB，单次新获取的原文件总量上限 160 MB。存储受到浏览器可用磁盘空间和配额限制，写入失败会显示提示。图库保留原有复制进度，收藏库另有持久记录。

ZIP 导出包含 collection.json 和 images/ 下的原文件，一次导出上限约 512 MB。当前没有整库导入功能，导出的图片与 JSON 可在文件管理器使用。

**保持本版安装目录不变，卸载前导出 ZIP。** 卸载扩展、删除浏览器配置或清理扩展站点数据可能清空本地库；更换安装路径导致插件 ID 改变时，旧库不会自动迁移。

特别版的本地库“复制整组”保留独立图片；切片的智能拼接继续使用 X 图库的原有流程或手动拼接窗口。真实 X 接口、QQ 与手机接收端仍需试用验证。

## 验证

整个仓库共 73 项可移植自动测试，包含六项持久队列测试。真实 Chromium 验证旧库迁移、四图顺序、失败与中断恢复、重复点赞无重复下载；100 张封面的首屏场景读取 24 张原文件，统计禁止加载全量 Blob 时正常，队列变化保留原卡片 DOM。该测量是构造页面的结果，不代表所有设备固定节省比例。

开发工作区还完成了模拟 X 的真实 Chromium 扩展测试、本地 IndexedDB、重复下载检查、字节去重、失败事务、搜索标签、手动发送确认、离线看图与 JPEG 复制、浏览器重启留存、原文件 ZIP 导出及删除共用文件保护。这不代表真实登录 X 或 QQ 已验收。
