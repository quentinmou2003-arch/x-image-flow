# Windows 多图剪贴板小助手

## 高清图批量复制修复（2.3.22 / lab.14 · 2026-11-10）

助手 1.3.1 修复把独立 PNG 的像素数累计后误判「整组图片尺寸过大」的问题。逐张准备、按原顺序复制，保持原分辨率和 PNG 字节，不自动缩图；保留每批 20 张、单张 40 MB、整批 200 MB，以及单张一亿像素 / 边长 32767 保护。GIF 总帧和拼接画布限制不变。整批成功才提交，失败保留勾选，避免漏复制。

更新扩展后也需运行新版 `native/安装小助手.cmd` 升级本机助手；只重新加载扩展不会更新已安装的 Windows 程序。旧助手触发此错误时会明确提示升级。Windows 原生协议测试已验证 20 张 3000×2000 PNG（合计 1.2 亿像素）逐张成功、文件名及字节不变；本次测试不向 QQ 发送消息。


安装器会优先识别当前目录已加载的 Chrome 扩展 ID，无法唯一确定时才手动填写；打开拾图设置自动检查连接。首次安装需要运行本地安装器，网页不能静默安装 Windows 程序。沿用助手 1.3.1，无常驻服务。

## 批量文件名（2.3.19 / 实验版 lab.10）

批量复制的 PNG 文件现在使用「作者名_发推时间_简短推文正文_推文编号_图02.png」，拼接图以「_拼接.png」结尾。描述来自推文文字，不调用识图服务或凭空生成描述；没有正文、正文归属不明确时使用推文编号。引用图片优先使用引用作者与对应正文。

自动缩短过长文字，过滤链接、换行、路径字符和 Windows 保留名称；同一批文件重名时追加后缀，顺序保持不变。复制、下载和实验版后续云端文件均使用上述命名；旧文件不改名，原图内容和出处不变。

**需要重新运行 native/安装小助手.cmd，升级到 1.3.1。** 旧助手会在下载转换前提示升级，不会静默退回数字名。Chrome 重新加载扩展后刷新 X。QQ 是否保留文件名取决于图片 / 文件粘贴方式与客户端版本，真实 QQ 待试用。

## 批量复制中拼接（2.3.19 / 实验版 lab.10）

在历史喜欢里开启「批量复制」，多图卡片会显示「独立图片 / 拼接一张」。普通图集逐张勾选；切片点击「拼接一张」，在预览中确认方向、顺序、片段和接缝，再点「确认拼接 · 加入批量」。疑似切片显示推荐，仍由你确认，不自动猜图。

一组确认的拼接图按一张输出计数，可以和单图、普通多图一起复制。确认会替换该组已选片段，沿用它们在队列中的首个位置；关闭预览不改变旧选择。「调整拼接」恢复上次参数；切回独立图片会移除该组拼接项，需要重新勾选片段。

每批最多 20 张输出 PNG，逐张处理，整批准备成功才写入剪贴板。导出固定使用确认预览的接缝，不再重新自动匹配。GIF / 视频不参与此批处理。需更新小助手到 1.3.1；整批 200 MB、每张 40 MB、单张一亿像素及边长 32767 的限制保留，独立 PNG 不再累计整批像素。QQ 接收形式待真实客户端试用。

批量拼接仅生成复制文件，不删除或替换本地库 / 云盘中的原片，不触发额外上传。

## 批量勾选复制（2.3.19 / 实验版 lab.10）

在「历史喜欢」的拾图界面点击顶部「批量复制」，卡片下方会展开每张照片的选择缩略图。逐张勾选，点击「复制所选 N 张」，然后切到 QQ 按 Ctrl+V。按勾选顺序放入多张独立 PNG，不自动发送，不改变 X 的点赞状态。

每批 1–20 张；切片也保留独立片段，可自行选需要的图片。切片可在预览确认后以拼接图加入队列；不包含 GIF 和视频；GIF 继续使用单独的「复制 GIF」。相同图片地址只选一次。支持清空、退出，失败保留选择；准备时切走页面会等待你回来再次点击复制。

**先重新运行 native/安装小助手.cmd，升级助手到 1.3.1**。每张最多 40 MB、整批最多 200 MB，解码像素也有上限。逐张准备以控制内存，完整准备后一次提交，避免失败只复制半套。QQ 可能显示为多张图片或文件，取决于 QQ 版本，请先试粘贴，不会自动发送。已验证真实 Windows 文件剪贴板，未验证真实 QQ 会话。

小助手只在复制整组或 GIF 时运行，断开连接后退出。不联网、不操作 QQ，不安装开机启动或常驻服务。程序由 Windows 自带 .NET Framework 在本机编译，主体约 15 KB，不需要另外安装 Python 或 Node.js。

## GIF 支持（助手 1.1.0）

已有安装请重新运行「安装小助手.cmd」，沿用当前插件 ID，不需要卸载。
卡片或预览点「复制 GIF」，在 QQ 按 Ctrl+V 并确认发送。剪贴板保留 GIF 文件与 GIF 数据，不附加静态 PNG / Bitmap；QQ 可能按动图或文件接收，需要以当前客户端试发为准。
转换在浏览器本地完成，不需要 FFmpeg 等额外软件。源 GIF 原样复制；视频形式转换有帧率、尺寸与调色板变化。

## 安装一次

1. 更新并重新加载拾图，刷新 X。
2. 在拾图顶部点「多图助手」，点「复制插件 ID」。
3. 双击本文件夹的「安装小助手.cmd」，将 ID 粘贴到安装窗口。
4. 回到拾图，点「检查连接」，看到连接成功即可。

安装到当前用户的 %LOCALAPPDATA%\XImageFlowClipboard，只注册 Chrome 当前用户的 Native Messaging 连接，无需管理员权限。升级或更换插件目录导致 ID 改变时，重新安装以登记新 ID。

## 收图

- 默认开启「点赞自动复制」。只有本次添加点赞成功后才复制，取消点赞和添加书签不复制。
- 单张图：复制原尺寸 PNG，不依赖小助手。
- 疑似切片：比较边缘，自动排列并拼接为一个 PNG。检测可能误判；请看接缝，必要时用原来的拼接窗口手动调整。
- 普通多图：按原顺序把每张图转为独立原尺寸 PNG，一次写入文件剪贴板。去 QQ 的手机会话按 Ctrl+V，由你确认发送。
- QQ 可能将文件剪贴板解释为图片或文件附件，具体取决于 QQ 版本；已验证 Windows 文件剪贴板，QQ 和手机接收端需实际试发确认。
- 视频不会复制为 PNG，混合推文只复制照片。
- 点赞成功但复制失败时，不撤销点赞；卡片「整组」按钮可重试，不必取消再点赞。

「已复制 2/4」只表示本标签页成功复制过两张图片，不代表发到 QQ。刷新保留最近 2000 张图片的复制记录。每次新复制都会替换剪贴板上一组，请先粘贴发送再收下一组。

## 缓存及卸载

PNG / GIF 文件暂存在 %TEMP%\XImageFlowClipboard，供 QQ 在助手退出后读取。下次整组复制时清理超过七天、且不在当前文件剪贴板中的缓存。

双击「卸载小助手.cmd」即可注销连接并移除助手程序。为保护尚未粘贴的图片，卸载不删除临时 PNG / GIF 缓存；Windows 临时文件清理工具可清理这些缓存。
