# Windows 多图剪贴板小助手

小助手只在复制整组或 GIF 时运行，断开连接后退出。不联网、不操作 QQ，不安装开机启动或常驻服务。程序由 Windows 自带 .NET Framework 在本机编译，主体约 15 KB，不需要另外安装 Python 或 Node.js。

## GIF 支持（助手 1.1.0）

已有安装请重新运行「安装小助手.cmd」，沿用当前插件 ID，不需要卸载。
卡片或预览点「复制 GIF」，在 QQ 按 Ctrl+V 并确认发送。剪贴板保留 GIF 文件与 GIF 数据，不附加静态 PNG / Bitmap；QQ 可能按动图或文件接收，需要以当前客户端试发为准。
转换在浏览器本地完成，不需要 FFmpeg 等额外软件。源 GIF 原样复制；视频形式转换有帧率、尺寸与调色板变化。

## 安装一次

1. 更新并重新加载拾图，刷新 X。
2. 在拾图顶部点「多图助手」，点「复制插件 ID」。
3. 双击本文件夹的「安装小助手.cmd」，将 ID 粘贴到安装窗口。
4. 回到拾图，点「检查连接」，看到连接成功即可。

安装到当前用户的 %LOCALAPPDATA%\XImageFlowClipboard，只注册 Chrome 当前用户的 Native Messaging 连接，无需管理员权限。升级或更换插件目录导致 ID 改变时，重新安装以登记新 ID。

## 收图

- 默认开启「点赞自动复制」。只有本次添加点赞成功后才复制，取消点赞和添加书签不复制。
- 单张图：复制原尺寸 PNG，不依赖小助手。
- 疑似切片：比较边缘，自动排列并拼接为一个 PNG。检测可能误判；请看接缝，必要时用原来的拼接窗口手动调整。
- 普通多图：按原顺序把每张图转为独立原尺寸 PNG，一次写入文件剪贴板。去 QQ 的手机会话按 Ctrl+V，由你确认发送。
- QQ 可能将文件剪贴板解释为图片或文件附件，具体取决于 QQ 版本；已验证 Windows 文件剪贴板，QQ 和手机接收端需实际试发确认。
- 视频不会复制为 PNG，混合推文只复制照片。
- 点赞成功但复制失败时，不撤销点赞；卡片「整组」按钮可重试，不必取消再点赞。

「已复制 2/4」只表示本标签页成功复制过两张图片，不代表发到 QQ。刷新保留最近 2000 张图片的复制记录。每次新复制都会替换剪贴板上一组，请先粘贴发送再收下一组。

## 缓存及卸载

PNG / GIF 文件暂存在 %TEMP%\XImageFlowClipboard，供 QQ 在助手退出后读取。下次整组复制时清理超过七天、且不在当前文件剪贴板中的缓存。

双击「卸载小助手.cmd」即可注销连接并移除助手程序。为保护尚未粘贴的图片，卸载不删除临时 PNG / GIF 缓存；Windows 临时文件清理工具可清理这些缓存。
