# 拾图 · 收藏实验室

## lab.12 云盘连接修复 · 2026-11-06

修复 Chrome 后台将原生 fetch 作为普通对象方法调用时触发 Illegal invocation 的问题；此前该异常被统一显示成「云盘网络中断」，即使授权完成也无法确认账号。现绑定浏览器全局对象后发出请求，无须因此重新建立 Google 客户端。

88 项自动测试通过，新增全局调用上下文回归测试；真实 Chromium 使用未替换的原生 fetch，验证可到达拦截的 HTTP 端点、401 正确识别为授权问题、账号解析成功。原有四图上传模拟回归保留。真实用户授权和上传仍需重新加载后验收，不能把模拟结果视为已入云。

## 简洁界面与设置（2.3.20 / 实验版 lab.12）

顶部只保留批量复制、设置和返回；实验版另保留本地库。排列、密度、预取、广告过滤、点赞自动复制 / 收下、隐藏记录、Windows 助手和 QQ 使用说明统一移到「设置」，原设置与功能保留。需要跨图拼接时才显示对应操作。

设置从右侧展开，关闭、Escape 或点击遮罩可返回浏览，支持键盘焦点与窄屏。打开设置时暂停自动续载，不在背后继续滚动。

实验版通过「设置 → Google Drive → 连接与设置」直接进入六步配置说明；本地库中的云盘与收图队列默认折叠，未完成的收图任务出现时展开队列。云端状态仍单独显示，配置客户端不等于完成授权。当前没有真实 Google 账号验收结果。

## 批量文件名（2.3.20 / 实验版 lab.12）

批量复制的 PNG 文件现在使用「作者名_简短推文正文_推文编号_图02.png」，拼接图以「_拼接.png」结尾。描述来自推文文字，不调用识图服务或凭空生成描述；没有正文、正文归属不明确时使用推文编号。引用图片优先使用引用作者与对应正文。

自动缩短过长文字，过滤链接、换行、路径字符和 Windows 保留名称；同一批文件重名时追加后缀，顺序保持不变。只改变复制临时文件的名称，不改动原图内容、来源或本地库 / 云盘文件。

**需要重新运行 native/安装小助手.cmd，升级到 1.3.0。** 旧助手会在下载转换前提示升级，不会静默退回数字名。Chrome 重新加载扩展后刷新 X。QQ 是否保留文件名取决于图片 / 文件粘贴方式与客户端版本，真实 QQ 待试用。

## 批量复制中拼接（2.3.20 / 实验版 lab.12）

在历史喜欢里开启「批量复制」，多图卡片会显示「独立图片 / 拼接一张」。普通图集逐张勾选；切片点击「拼接一张」，在预览中确认方向、顺序、片段和接缝，再点「确认拼接 · 加入批量」。疑似切片显示推荐，仍由你确认，不自动猜图。

一组确认的拼接图按一张输出计数，可以和单图、普通多图一起复制。确认会替换该组已选片段，沿用它们在队列中的首个位置；关闭预览不改变旧选择。「调整拼接」恢复上次参数；切回独立图片会移除该组拼接项，需要重新勾选片段。

每批最多 20 张输出 PNG，逐张处理，整批准备成功才写入剪贴板。导出固定使用确认预览的接缝，不再重新自动匹配。GIF / 视频不参与此批处理。无需更新已安装的 1.3.0 小助手；整批 200 MB、每张 40 MB 和总像素限制继续有效。QQ 接收形式待真实客户端试用。

批量拼接仅生成复制文件，不删除或替换本地库 / 云盘中的原片，不触发额外上传。

## 批量勾选复制（2.3.20 / 实验版 lab.12）

在「历史喜欢」的拾图界面点击顶部「批量复制」，卡片下方会展开每张照片的选择缩略图。逐张勾选，点击「复制所选 N 张」，然后切到 QQ 按 Ctrl+V。按勾选顺序放入多张独立 PNG，不自动发送，不改变 X 的点赞状态。

每批 1–20 张；切片也保留独立片段，可自行选需要的图片。切片可在预览确认后以拼接图加入队列；不包含 GIF 和视频；GIF 继续使用单独的「复制 GIF」。相同图片地址只选一次。支持清空、退出，失败保留选择；准备时切走页面会等待你回来再次点击复制。

**先重新运行 native/安装小助手.cmd，升级助手到 1.3.0**。每张最多 40 MB、整批最多 200 MB，解码像素也有上限。逐张准备以控制内存，完整准备后一次提交，避免失败只复制半套。QQ 可能显示为多张图片或文件，取决于 QQ 版本，请先试粘贴，不会自动发送。已验证真实 Windows 文件剪贴板，未验证真实 QQ 会话。

独立特别版 **2.4.0-lab.12**（Chrome 内部版本 2.4.0.12），核对日期 2026-11-05。稳定版仍为 2.3.20，本版不替换稳定版的安装包。

目标是让收图从“刷到、复制”继续走到“留存、找回、整理”。原有顺序收图、图集、自动复制、拼接、点赞、书签、推广过滤和本机多图助手保留。

## 复制 GIF

- GIF 卡片、动图播放窗口和原 GIF 大图预览提供「复制 GIF」，通过小助手写入真正的 GIF 文件与 GIF 剪贴板格式，不附加静态 PNG / Bitmap。
- 源文件本身是 GIF 时保留字节、透明关系、帧延时和循环；X 以 MP4 提供的动图在浏览器本地完整转换，不上传转换网站、不依赖 FFmpeg。
- 视频形式转 GIF 最多 640 像素长边、约 12 帧 / 秒、256 色；为控制资源，长动图可能进一步缩小。支持 2 分钟以内且输入 / 输出不超过 40 MB，超限提示失败，不截取前几秒冒充完整动图。
- **已有用户须重新运行 native/安装小助手.cmd 升级到 1.1.0**；旧助手会明确提示升级。普通单图 PNG 不需要小助手。

## 自动续载

- 打开拾图即自动补充内容，接近图库底部、继续向下滚动或触碰底部时自动续载，不必点加载按钮。
- 自动续载不再依赖「极速预取」开关；该开关只影响图片预取与提前加载距离。
- X 暂无新图片时按 2、4、8、16、30 秒逐渐延长间隔重试，不再一次空批次就永久停止。保留手动立即重试。
- 只准备附近几屏；关闭拾图、打开大图或菜单、切到后台、断网时暂停。识别原页面滚动容器，支持媒体页内部滚动。

## 返回作者主页

- 作者主页、媒体页中新增「@ID 主页」入口，在当前标签页打开作者主页并退出拾图，不新开页面。
- 顶部退出按钮按入口显示「返回媒体页」「返回 @ID」「返回 X 首页」等，避免把作者页与 X 首页混淆。
- 从图库切换历史喜欢、书签或首页时，本标签页保留最初入口；顶部返回按钮可回到原页面。「回首页收新图」仍是独立入口。

## 连接恢复

- 等待图片处理接收端真正就绪后才发请求，并发操作共用一次启动。处理端意外断开时，图片准备最多恢复一次。
- 复制、拼接预览、下载、整组复制和特别版离线整组复制使用同一连接检查。不会重发点赞、收藏或 Windows 剪贴板提交。
- 图片处理端错误不会误判为后台断线；后台首次唤醒失败短暂自动重试，持续失败可点「重试连接」。

## 试用

下载预发行页中的 x-image-flow-lab-v2.4.0.12.zip，解压后覆盖原特别版目录，重新加载并刷新 X。ZIP 根目录直接包含 manifest.json。

**试用时在 Chrome 扩展管理页暂时关闭稳定版，不必卸载**，避免两个拾图同时在同一 X 页面工作。关闭特别版并重新启用稳定版即可回退。

特别版有独立的插件 ID、偏好和收藏库。普通多图剪贴板需要在「多图助手」复制本版 ID，重新运行 native/安装小助手.cmd 登记；安装器保留原来允许的 ID。

在 X 卡片点「收下」保存整条推文的照片与出处，点击顶部「本地库」查看。**收下不触发 X 点赞或书签**。仅收照片，视频暂不归档。

## 数据与边界

收藏库和待处理队列存在本扩展自己的 IndexedDB 中，不上传到项目维护者或独立服务器。手动收下或开启自动收下后的新增点赞会获取原图，作者和来源随图保存。精确重复提醒与去重不等于相似图片识别。

仅归档 X 推文照片，一组最多四张；单文件上限 64 MB，单次新获取的原文件总量上限 160 MB。存储受到浏览器可用磁盘空间和配额限制，写入失败会显示提示。图库保留原有复制进度，收藏库另有持久记录。

ZIP 导出包含 collection.json 和 images/ 下的原文件，一次导出上限约 512 MB。当前没有整库导入功能，导出的图片与 JSON 可在文件管理器使用。

**保持本版安装目录不变，卸载前导出 ZIP。** 卸载扩展、删除浏览器配置或清理扩展站点数据可能清空本地库；更换安装路径导致插件 ID 改变时，旧库不会自动迁移。

特别版的本地库“复制整组”保留独立图片；切片的智能拼接继续使用 X 图库的原有流程或手动拼接窗口。真实 X 接口、QQ 与手机接收端仍需试用验证。
