# 拾图 · 收藏实验室 2.4.0-lab.9

## 批量复制中拼接（2.3.18 / 实验版 lab.9）

在历史喜欢里开启「批量复制」，多图卡片会显示「独立图片 / 拼接一张」。普通图集逐张勾选；切片点击「拼接一张」，在预览中确认方向、顺序、片段和接缝，再点「确认拼接 · 加入批量」。疑似切片显示推荐，仍由你确认，不自动猜图。

一组确认的拼接图按一张输出计数，可以和单图、普通多图一起复制。确认会替换该组已选片段，沿用它们在队列中的首个位置；关闭预览不改变旧选择。「调整拼接」恢复上次参数；切回独立图片会移除该组拼接项，需要重新勾选片段。

每批最多 20 张输出 PNG，逐张处理，整批准备成功才写入剪贴板。导出固定使用确认预览的接缝，不再重新自动匹配。GIF / 视频不参与此批处理。无需更新已安装的 1.2.0 小助手；整批 200 MB、每张 40 MB 和总像素限制继续有效。QQ 接收形式待真实客户端试用。

批量拼接仅生成复制文件，不删除或替换本地库 / 云盘中的原片，不触发额外上传。

## 批量勾选复制（2.3.18 / 实验版 lab.9）

在「历史喜欢」的拾图界面点击顶部「批量复制」，卡片下方会展开每张照片的选择缩略图。逐张勾选，点击「复制所选 N 张」，然后切到 QQ 按 Ctrl+V。按勾选顺序放入多张独立 PNG，不自动发送，不改变 X 的点赞状态。

每批 1–20 张；切片也保留独立片段，可自行选需要的图片。切片可在预览确认后以拼接图加入队列；不包含 GIF 和视频；GIF 继续使用单独的「复制 GIF」。相同图片地址只选一次。支持清空、退出，失败保留选择；准备时切走页面会等待你回来再次点击复制。

**先重新运行 native/安装小助手.cmd，升级助手到 1.2.0**。每张最多 40 MB、整批最多 200 MB，解码像素也有上限。逐张准备以控制内存，完整准备后一次提交，避免失败只复制半套。QQ 可能显示为多张图片或文件，取决于 QQ 版本，请先试粘贴，不会自动发送。已验证真实 Windows 文件剪贴板，未验证真实 QQ 会话。

这是独立特别版，Chrome 内部版本为 2.4.0.9，稳定版 2.3.18 保留。

## 点赞自动收下

默认开启「点赞自动收下」。在拾图中新增点赞成功后，整组照片原文件、作者、出处与顺序自动加入本机收图队列，可在顶部关闭。取消点赞、失败的点赞和历史已有点赞不触发归档。手动「收下」仍可用。

本地库顶部能看到等待、保存中和失败任务。失败按 1、2、4、8 分钟间隔重试，五次失败后可手动重试；浏览器关闭时暂停，重新启动后恢复。全部原图保存成功才显示「已收下」，失败不会留下半套收藏。复制和保存是独立流程，取消点赞不删已存图片。

图库统计不再读出全部原图，封面靠近视口才加载；队列更新不重建图库卡片。升级保留旧库与标签。

Google Drive 接入已实现于 lab.8，需按安装包内《Google Drive 使用说明》配置 OAuth 客户端，再主动点击「连接并同步收藏」。连接后同步本机已有和后续收下的照片原文件及作者、出处、图序、标签清单；切片仍保存每张原片，不以拼接图替代。原文件哈希去重，按账号隔离续传与任务状态，整组及清单校验完成后才显示已入云。断开连接保留云端文件。本版无双向恢复和自动分类；真实 Google 登录上传尚待用户账号验收，未连接前仍只存本机。 照片切片保留每张原片，未自动额外存合成图；视频与 MP4 形式动图暂不归档。后台恢复需要 Chrome 运行，不安装系统常驻程序。

## 连接错误不再误判

- 图片处理端短暂未就绪时，只提示重试当前图片操作，不再误报整个插件后台断线。
- 插件后台首次唤醒失败时自动短暂重试两次；持续失败的横幅新增「重试连接」，成功后无需刷新本轮图库。
- 扩展文件真正更新后仍需重新加载拾图并刷新 X；连接重试不会重复点赞、收藏、下载或剪贴板提交。

## 直接复制 GIF

- GIF 卡片、动图播放窗口和原 GIF 大图预览提供「复制 GIF」，通过小助手写入真正的 GIF 文件与 GIF 剪贴板格式，不附加静态 PNG / Bitmap。
- 源文件本身是 GIF 时保留字节、透明关系、帧延时和循环；X 以 MP4 提供的动图在浏览器本地完整转换，不上传转换网站、不依赖 FFmpeg。
- 视频形式转 GIF 最多 640 像素长边、约 12 帧 / 秒、256 色；为控制资源，长动图可能进一步缩小。支持 2 分钟以内且输入 / 输出不超过 40 MB，超限提示失败，不截取前几秒冒充完整动图。
- **已有用户须重新运行 native/安装小助手.cmd 升级到 1.2.0**；旧助手会明确提示升级。普通单图 PNG 不需要小助手。

## 自动续载

- 打开拾图即自动补充内容，接近图库底部、继续向下滚动或触碰底部时自动续载，不必点加载按钮。
- 自动续载不再依赖「极速预取」开关；该开关只影响图片预取与提前加载距离。
- X 暂无新图片时按 2、4、8、16、30 秒逐渐延长间隔重试，不再一次空批次就永久停止。保留手动立即重试。
- 只准备附近几屏；关闭拾图、打开大图或菜单、切到后台、断网时暂停。识别原页面滚动容器，支持媒体页内部滚动。

## 返回作者主页

- 作者主页、媒体页中新增「@ID 主页」入口，在当前标签页打开作者主页并退出拾图，不新开页面。
- 顶部退出按钮按入口显示「返回媒体页」「返回 @ID」「返回 X 首页」等，避免把作者页与 X 首页混淆。
- 从图库切换历史喜欢、书签或首页时，本标签页保留最初入口；顶部返回按钮可回到原页面。「回首页收新图」仍是独立入口。

## 连接错误修复

- 等待图片处理接收端真正就绪后才发请求，并发操作共用一次启动。处理端意外断开时，图片准备最多恢复一次。
- 复制、拼接预览、下载、整组复制和特别版离线整组复制使用同一连接检查。不会重发点赞、收藏或 Windows 剪贴板提交。
- 页面连接真正失效时提供刷新 / 重新加载提示；图片处理错误与后台断线分别说明。

已有特别版请将新文件覆盖到原安装目录，重新加载扩展并刷新 X；不要卸载，以保留本地收藏。

## 开始试用

1. 在 Chrome 扩展管理页暂时关闭稳定版，不用卸载。
2. 加载解压后包含 manifest.json 的特别版文件夹，并刷新 X。
3. 点击拾图。卡片「收下」把整组照片和作者、出处一起保存，不需要点赞。
4. 顶部「本地库」打开收藏实验室，可以离线看图、搜索作者、编辑标签和整理进度。
5. 普通多图剪贴板需要在「多图助手」复制本版 ID，运行 native/安装小助手.cmd 登记。

## 防漏清单

图库增加「未收下」「收过」「待复制」「已复制」筛选；收过同一原图 URL 会提示，仍可保存新的推文出处。单图和普通多图保留已有复制流程，切片智能拼接仍在 X 图库中使用。
本地库中的「我已发送」由你手动确认，程序不会检查 QQ 或自动发送。收藏、复制、发送是独立状态。

## 原文件与去重

保存 X 当前能获取的 orig 原文件，JPEG 保持 JPEG、PNG 保持 PNG，导出不做额外压缩。并不保证取得博主上传前的文件。
同 URL 避免重新下载；字节相同的原文件用 SHA-256 共用存储。不保证识别相似图或更高清版本。整组获取失败不会写入半套收藏。

## 保留与导出

点「导出收藏 ZIP」导出原图和 collection.json，其中含作者、出处、标签、状态及每张原图文件对应关系。一次导出约 512 MB 上限，当前没有整库导入功能。
收藏在本扩展的本机 IndexedDB，断网可查看已收原图。保持安装目录不变，卸载、清理浏览器扩展数据或删除配置前，请先导出。
试用结束关闭特别版、启用稳定版并刷新 X 即可，特别版收藏不会自动迁移到稳定版。

本次验证使用构造 X 页面、真实 Chromium 扩展和本地数据库。真实 X、QQ 和手机接收端需要试用验收。
