# 收藏实验室的数据与云端授权

本版为独立预发行扩展。原文件、作者显示名称、作者主页、推文来源、标签与处理状态保存在本扩展的 IndexedDB 中，不上传给项目维护者，没有统计埋点或独立服务器。

用户点击「收下」，或默认开启「点赞自动收下」后在拾图中新增点赞确认成功，才会获取 X 当前提供的 orig 原图。可关闭自动收下；不批量导入历史点赞。任务与失败状态保存在本机，alarms 权限只用于 Chrome 运行时重试未完成任务。同一 URL 复用已存文件，相同字节通过 SHA-256 去重，启用云端后摘要随校验信息保存至用户自己的 Drive。

Google Drive 为用户主动启用功能，使用 Chrome identity 与 drive.file 权限，仅访问本应用创建或用户授予的文件。连接后会向用户自己的 Google Drive 上传本机已有及后续保存的原图、作者、出处、图序、标签和 SHA-256 摘要；不上传给维护者，不自动创建公开分享。访问令牌只在后台内存及 Chrome 授权缓存中使用，不写入本机收藏、来源清单或日志。账号标识、邮箱与续传记录保存在本机以隔离账号、恢复任务；断开后停止上传，已上传文件保留。可在 Google 账号中撤销应用权限。没有登录授权和配置客户端 ID 时不会上传。

搜索、标签编辑、已发送确认、离线预览和 ZIP 导出均在本地处理。「我已发送」由用户手动设置，不读取 QQ 会话、不自动发送消息。

图片复制保留稳定版的行为。Windows 多图助手只接收要复制的 PNG / GIF，在当前用户临时目录生成文件并写入剪贴板，退出后 QQ 仍可读取文件。助手不联网、不常驻；缓存超过七天且不在当前文件剪贴板中时，在下一次整组复制中清理。

删除收藏会移除该条来源记录；其他收藏仍引用的原图保留，最后一个引用删除时同时移除原图。卸载扩展、清理浏览器数据或删除配置可能清空收藏库，请先导出原图与来源 ZIP。

用户在 X 图库点击复制 GIF 时会读取 video.twimg.com 的动图视频，在本机浏览器转换。没有远程转换服务，不向维护者上传媒体。
