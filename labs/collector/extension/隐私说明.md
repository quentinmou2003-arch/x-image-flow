# 收藏实验室的本地数据

本版为独立预发行扩展。原文件、作者显示名称、作者主页、推文来源、标签与处理状态保存在本扩展的 IndexedDB 中，不上传给项目维护者，没有统计埋点或独立服务器。

只有用户点击「收下」才获取 X 当前提供的 orig 原图；同一 URL 已保存在库中时复用本地文件，相同字节的原文件通过 SHA-256 共用存储。这些摘要用于本地去重，不发送给第三方。

搜索、标签编辑、已发送确认、离线预览和 ZIP 导出均在本地处理。「我已发送」由用户手动设置，不读取 QQ 会话、不自动发送消息。

图片复制保留稳定版的行为。Windows 多图助手只接收要复制的 PNG，在当前用户临时目录生成文件并写入剪贴板，退出后 QQ 仍可读取文件。助手不联网、不常驻；缓存超过七天且不在当前文件剪贴板中时，在下一次整组复制中清理。

删除收藏会移除该条来源记录；其他收藏仍引用的原图保留，最后一个引用删除时同时移除原图。卸载扩展、清理浏览器数据或删除配置可能清空收藏库，请先导出原图与来源 ZIP。
