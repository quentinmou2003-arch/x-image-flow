这是我的第一个 GitHub 项目。从自己在 X 上收图的需求出发，我借助 AI 辅助开发，逐步做出了图片瀑布流、卡牌图集、拼接和原尺寸 PNG 复制功能。

## 安装

目前通过本地加载安装，尚未上架 Chrome 网上应用店。

**[下载最新安装包](https://github.com/quentinmou2003-arch/x-image-flow/releases/latest)**：下载发布页中的 `x-image-flow-v2.3.11.zip` 并解压，加载包含 `manifest.json` 的目录即可。也可以按下面步骤下载完整源码安装。

1. 点击仓库上方 **Code → Download ZIP**，解压到一个固定目录。
2. 打开 Chrome 的 `chrome://extensions`，开启右上角的**开发者模式**。
3. 点击**加载已解压的扩展程序**，选择项目中的 **`extension` 文件夹**。
4. 刷新已登录的 X 页面，点击扩展图标，或页面右下角的「拾图 · 图片与视频」。

**Windows 多图小助手（安装一次）**：顶部「多图助手 → 复制插件 ID」，双击安装包 native 文件夹中的「安装小助手.cmd」，粘贴 ID，再点「检查连接」。无需管理员权限，按需启动，无联网或 QQ 自动操作。详情见 [小助手使用说明](extension/native/使用说明.md)。

升级时替换原目录中的文件，在扩展管理页点击重新加载，再刷新 X。请保留安装目录。

## 使用小贴士

- **广告过滤**：默认开启。顶部「广告已屏蔽」可切换；只过滤 X 明确标记的推广，不识别未标记的软广告。过滤作用于拾图图库。
- **点赞即复制**：默认开启，取消点赞不复制。普通多图复制成独立 PNG 文件列表，切片按检测结果自动拼接；QQ 的粘贴形式可能是图片或文件附件，需要试发确认。复制失败保留点赞，可用卡片「整组」重试。
- **防漏图**：默认「顺序收图」，卡片位置固定；底部进度表示已写入剪贴板，不代表已经发送 QQ。请先粘贴上一组再复制下一组。
- **收新图**：在首页切换「为你推荐 / 正在关注」。从历史收藏返回时，点击「回首页收新图」。
- **发 QQ**：点击「复制 PNG」，等复制成功后切到 QQ 的手机会话粘贴发送。插件不会自动发送消息。要保留文件，请保存后以文件形式发送。
- **看细节**：点击图片进入预览，滚轮或加减按钮缩放；放大后拖动，点击「适应」恢复全图。上一张、下一张固定在预览区两侧。
- **点赞和书签**：优先在当前页面调用 X 网页接口，不再新开推文标签页。首次使用按提示在 X 原网页正常操作一次；添加和取消操作分别学习，接口格式保存在本地，登录凭据仅留在页面内存。
- **拼接**：点图集的「拼接」，或选择 2–4 张图跨推文拼接。片段旁的 × 只从本次拼接移除图片。
- **PNG 的含义**：导出不会再做 JPEG 有损压缩，但将 JPEG 转成 PNG 不会恢复原来已经丢失的细节，文件通常更大。

## 当前限制

- 只处理 X 已经加载的内容，历史喜欢、书签需要随浏览逐步加载；不是一次性导出整个账号。
- 推文计数来自 X 已返回的数据，拿不到时显示「—」。X 页面和数据结构变化可能影响功能。
- 拼接不能还原原切片缺失的内容，也不能保证所有图集都能无缝对齐。
- 图库已取消 600 组限制；X 返回新内容时可继续加载。远处预览会卸载，但本轮记录仍占用内存，刷新可清空。
- 点赞、书签使用 X 未公开保证兼容的网页接口；接口变化后可能需要重新学习。当前接口测试使用模拟请求，真实 X 兼容性仍需试用验证。
- 视频播放依赖可取得的 MP4 地址。
- 这是独立的个人项目，与 X、QQ 无隶属关系。请尊重原作者的作品权利。

## 开发

扩展使用原生 JavaScript、CSS 和 Chrome Manifest V3，无构建步骤。

```text
extension/          可直接加载的扩展
  content.js        图库、交互和 X 页面提取
  ad-filter.js     推广数据与广告标记识别
  video-bridge.js   读取 X 已返回的媒体数据
  social-bridge.js  在当前 X 页面学习并调用互动接口
  social-protocol.js 操作格式校验与成功确认
  collection-flow.js 自动收图计划与切片判断
  native-copy.js    Windows Native Messaging 整组复制
  native/           轻量 Windows 小助手源码、安装及卸载
  native-menu.js    X 原菜单、后续弹窗与原帖定位
  background.js     后台任务和下载
  offscreen.js      图像解码与 PNG 输出
  stitch.js         拼接匹配
  icons/            像素 X 图标
tests/              可移植的基础测试
docs/FEATURE_STATUS.md 功能实现状态与验证范围
```

安装 Node.js 20 或更新版本后，在项目目录运行：

```sh
npm test
```

基础测试不依赖真实 X 账号；真实页面兼容性还需要在登录的 Chrome 中验证。
