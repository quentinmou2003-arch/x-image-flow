这是我的第一个 GitHub 项目。从自己在 X 上收图的需求出发，我借助 AI 辅助开发，逐步做出了图片瀑布流、卡牌图集、拼接和原尺寸 PNG 复制功能。

## 能做什么

| 功能 | 使用体验 |
| --- | --- |
| 图片与视频瀑布流 | 提取当前 X 页面加载的媒体，按视口预载，支持三种密度 |
| 卡牌图集 | 同一条推文的多张图片叠成一组，左右切换 |
| 高清看图 | 滚轮缩放、双击放大、拖动查看细节 |
| 收藏与出处 | 同步点赞、书签到 X，显示可取得的推文计数和引用作者 |
| 历史收藏 | 打开历史喜欢、书签后自动进入拾图，也可返回首页继续收图 |
| 原尺寸 PNG | 复制到剪贴板或保存为 PNG 文件，方便手动发到 QQ |
| 图片拼接 | 横拼、竖拼、四宫格，检测重叠，手动调整接缝、顺序和片段 |
| 低清视频预览 | 点击才播放，优先最低可用码率，可切换清晰度 |

## 安装

目前通过本地加载安装，尚未上架 Chrome 网上应用店。

1. 点击仓库上方 **Code → Download ZIP**，解压到一个固定目录。
2. 打开 Chrome 的 `chrome://extensions`，开启右上角的**开发者模式**。
3. 点击**加载已解压的扩展程序**，选择项目中的 **`extension` 文件夹**。
4. 刷新已登录的 X 页面，点击扩展图标，或页面右下角的「拾图 · 图片与视频」。

升级时替换原目录中的文件，在扩展管理页点击重新加载，再刷新 X。请保留安装目录。

## 使用小贴士

- **收新图**：在首页切换「为你推荐 / 正在关注」。从历史收藏返回时，点击「回首页收新图」。
- **发 QQ**：点击「复制 PNG」，等复制成功后切到 QQ 的手机会话粘贴发送。插件不会自动发送消息。要保留文件，请保存后以文件形式发送。
- **看细节**：点击图片进入预览，滚轮或加减按钮缩放；放大后拖动，点击「适应」恢复全图。
- **拼接**：点图集的「拼接」，或选择 2–4 张图跨推文拼接。片段旁的 × 只从本次拼接移除图片。
- **PNG 的含义**：导出不会再做 JPEG 有损压缩，但将 JPEG 转成 PNG 不会恢复原来已经丢失的细节，文件通常更大。

## 当前限制

- 只处理 X 已经加载的内容，历史喜欢、书签需要随浏览逐步加载；不是一次性导出整个账号。
- 推文计数来自 X 已返回的数据，拿不到时显示「—」。X 页面和数据结构变化可能影响功能。
- 拼接不能还原原切片缺失的内容，也不能保证所有图集都能无缝对齐。
- 每轮图库最多收集 600 组媒体；视频播放依赖可取得的 MP4 地址。
- 这是独立的个人项目，与 X、QQ 无隶属关系。请尊重原作者的作品权利。

## 开发

扩展使用原生 JavaScript、CSS 和 Chrome Manifest V3，无构建步骤。

```text
extension/          可直接加载的扩展
  content.js        图库、交互和 X 页面提取
  video-bridge.js   读取 X 已返回的媒体数据
  background.js     后台任务和下载
  offscreen.js      图像解码与 PNG 输出
  stitch.js         拼接匹配
  icons/            像素 X 图标
tests/              可移植的基础测试
```

安装 Node.js 20 或更新版本后，在项目目录运行：

```sh
npm test
```

基础测试不依赖真实 X 账号；真实页面兼容性还需要在登录的 Chrome 中验证。
